# Increment 1 Requirements

## 1. Overview
Start working on the project using the attached `Utterances.txt` file.

## 2. Utterances File Format
- **Separator**: A `#` symbol separates the user input and the program's response.
- **Wildcard**: A `*` in the file indicates a user input that is not listed in the file. In this case, a general response should be given.
- **Evolution**: This file will continue to evolve as the project progresses.

## 3. Deliverables
- A working program implementing this initial interface should be completed over the weekend.
- **Sample Data**: A sample file with home loan related details is provided. Similar files will be shared later for other types of loans.
